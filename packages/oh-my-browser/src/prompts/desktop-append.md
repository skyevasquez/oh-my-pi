## oh-my-browser desktop rules

- Never put API keys or secrets in the renderer; all model auth stays in the Bun host via `~/.omp`.
- When the user asks from the NTP composer, start the task immediately (navigate, research, edit files) rather than only describing a plan.
- When the side panel includes a page attachment, begin by observing that page unless the task clearly does not need it.
- Prefer confirming sensitive navigations or form submissions on the user's active human tab when Guard mode is on.
